# How Window Peeper AI reviews sources and tests

A summary of the [editorial method](https://windowpeeperai.pro/about) behind [Window Peeper AI](https://windowpeeperai.pro/), maintained by chaozicoder (updated 2026-10-23).

## Source handling

- Platform listings, original posts, third-party reports, model documentation and own observations are kept separate.
- A source's publication date is different from the date it was read.
- Unavailable links stay unavailable; missing figures are not turned into zero.
- A template's release date does not establish the whole meme's origin.

Concept illustrations are labelled and never counted as real videos. Failed tests stay in the private test history.

## Updates

Source links and outside policies are reviewed manually each week, and affected claims are rechecked when model, price or permission facts change. Meaningful edits update page dates; a fresh date is not a substitute for new evidence.
